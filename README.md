# Smart 재무설계

> AI를 활용한 6단계 재무설계 프로그램 — 가계부를 연동해 계획이 실제로 지켜지는지 실시간으로 점검하는 목표 기반 재무설계 워크스페이스

가상 고객 사례(이OO 씨 가족)를 기준으로, 상담 → 분석 → 대안 설계 → 실행 → 점검까지 재무설계 전 과정을 하나의 웹 화면에서 확인할 수 있도록 만든 프로젝트입니다. 단일 HTML 파일로 동작하며 별도 설치가 필요 없습니다.

## 내가 맡은 역할

> 이 프로젝트는 [팀원 이름]과 함께 진행한 공동 작업입니다. 아래는 제가 직접 기획한 부분입니다.

- **고객 사례 기획**: 프로그램에 적용된 가상 고객(이직한 40대 가장, 무직 배우자, 초등학생 자녀)의 인적 사항, 재무 상황, 상담 목표, 시나리오를 직접 설계했습니다.
  - 은퇴 목표(월 200만 원 기본, 월 250만 원 조건부), 주거 안정, 비상금 2,000만 원 등 고객의 목표와 제약 조건
  - 무조치 / 원래 전세 계획 / 설계안 적용의 3가지 비교 시나리오
- **재무설계 단계별 대시보드 구성요소 기획**: 6단계 각각에서 어떤 정보를 어떤 형태(지표, 비교표, 차트, 점검 카드)로 보여줄지 정했습니다.
- **구현 방식**: [AI 도구 이름, 예: Claude]를 활용해 기획 내용을 코드로 구현했습니다. *(실제 활용 방식에 맞게 수정하세요)*

## 주요 기능: 재무설계 6단계

| 단계 | 화면 구성 |
|---|---|
| **1. 관계 설정** | 부부가 지키고 싶은 생활과 상담 목표 확인 |
| **2. 정보 수집** | 증빙서류 제출(원천징수영수증, 급여명세서, 국민연금 가입내역서, 보험증권, 예금잔액증명서 등 11종), 서류 없이 직접 입력, 투자 성향 설문(11문항), 단기·중기·장기 목표 수립 |
| **3. 분석·평가** | 재무건전성, 현금흐름·주거, 노후 준비, 세금·증빙, 투자 성향 |
| **4. 대안 설계** | 대안 비교, 자산배분, 비상금 회복, 노후자금, 스트레스 테스트 |
| **5. 실행 결정** | 상담에서 합의한 계획과 점검 시점 기록 |
| **6. 점검·수정** | 실시간 점검, 비상금 회복, 노후자금 진행률, 전망과 산출 근거 |

### 눈여겨볼 대시보드 구성
- **대안 비교**: 목사 시절 / 무조치 / 설계안 적용 세 시나리오의 소득, 지출, 월 잉여현금, 순자산, 부채비율을 한 표에서 비교
- **노후자금 점검**: 월 200만 원·250만 원 목표별 필요 금액, 확보 금액, 부족액, 충족률과 적립 잔액 전망 차트
- **스트레스 테스트**: 금리 상승, 소득 중단, 큰 의료비, 보증금 급등, 복합 충격을 입주 직후·전세 만기·58세 시점별로 시험하고 통과 / 조건부 통과 / 실패로 판정
- **비상금 회복 점검**: 24개월 비상금 잔액 전망과 위기 발동 조건(비상금 부족, 저축 여력 부족, 예정 지출 초과) 점검
- **IRP·ISA 절세 시뮬레이션**: 금액을 바꿔 가며 지방소득세를 포함한 절세 효과 계산
- **가계부 연동**: 실제 수입·지출 기록을 계획과 비교해 점검 결과에 반영

## 사용 방법
1. 저장소의 `B안_재무이음_강희훈, 심우찬_별도.html` 파일을 내려받습니다. *(파일 이름을 `index.html` 등으로 바꾸면 더 편합니다.)*
2. 웹 브라우저(Chrome 권장)로 열면 바로 실행됩니다.
3. 입력한 내용은 사용 중인 브라우저에 자동 저장되며, 고객 정보는 서버로 전송되지 않습니다.
